## 未采纳 / 存疑

- **"主 CTA 改用冰蓝或钢白，琥珀只留给导航"**（deepseek）：不采纳。冰蓝在 4.0 的分工是"数据通道（图表/读数）"，把它给主 CTA 会让"数据"和"动作"再次混淆；琥珀留在导航（位置）+ 主 CTA（动作）两处是刻意取舍，其余全部收掉后不再摊薄。
- **"`.pill.on` 恢复绿底"**：只采纳一半。绿底块在暗色 hero 上仍是四块彩色强调；改成中性底 + 绿点，信息在圆点里，不在整块发亮。
- **"刻度脊需要主次刻度 + 条件琥珀"**（gpt）：采纳并加强，见 4.0.1 ㉚——轴线（1px 连续）+ 横向刻度（5px 宽 1px 高，8px 间隔）+ 48px 主刻度，配上下 10px 的 mask 淡出，才读得出"刻度"而不是"虚线边框"。
- **"安装时应在停车/夜间亮度/戴手套条件下实测 3 秒达成率"**（gpt）：认可，未做——需要你在车边实测，我不替你声称这个数字。

## 遗留债（需改 HTML/JS，不在 CSS 覆盖层能力内）

1. 画布网格、事件标记、采样点的颜色仍散落在 `app.js` 里，本轮只对齐了 4 个主色；彻底解决要把画布色板提到 CSS 变量 + `getComputedStyle` 读取。
2. 空调卡"三个控件说同一件事"只能隐掉一行；真正的信息合并（时长并入主按钮）要动 DOM。
3. `--sub` 提亮后仍未逐一复核全部 546 个选择器的对比度；本次只覆盖了标签层与读数层。
