# BYD 控车 · UI 4.0 设计计划

> 参照 `lark-apps/creative-design/references/frontend-design.md` 的流程：先钉住主题，再填满四个槽位，最后才写代码。
> 基线版本：versionCode 609 / 3.20.83-secure6（已备份，见文末）。

## 主题钉死

这是一台**停在夜里的车，手机贴在挡把旁边**。用户在这个界面上只做三件事：看一眼车还在不在、按一下开门、上车前扫一眼波形确认信号。
受众是车主本人，单手、可能戴手套、屏幕在暗环境里刺眼。界面唯一的任务是**让人在 3 秒内确认状态并完成一次操作**。

## 四个槽位

**世界（World）**：夜间驾驶舱的仪表台。不是"科技感 App"，是**仪表**——指针式的东西，刻度环、丝印标签、琥珀背光的警示灯、玻璃罩。

**材质（Materials）**：
- 哑光石墨搪塑（卡片底、页面底）——比纯黑偏中性、几乎不加蓝
- 拉丝铝（分隔线、卡片刻度脊、导航栏上沿）
- 琥珀背光（唯一强调光：选中、主操作、通电指示）
- 玻璃罩反光（卡片顶部一道低角度高光，45° 渐变，不是居中外发光）
- 丝印白（标签文字，小号 + 宽字距，像仪表盘上的印刷字）

**配色（Palette）**——6 个命名值：

| token | hex | 职责 |
|---|---|---|
| `--v4-graphite` | `#0B0D10` | 页面底，中性石墨 |
| `--v4-panel` | `#131A20` | 面板/卡片 |
| `--v4-steel` | `#8B97A5` | 次要文字、刻度脊、分隔线 |
| `--v4-amber` | `#E8A13A` | **唯一强调**：主按钮、选中态、通电指示 |
| `--v4-ice` | `#63C4DE` | 数据通道：波形曲线、已连接、实时读数 |
| `--v4-alert` | `#D9615A` | 破坏性/停扫/异常（降饱和，仪表红灯的调子） |

语义色只做三档：`ok → #4CC38A`、`warn → #E5B24A`、`danger → #D9615A`。**不引入第四种强调色**。

**字体（Type）**：
- 标签层：11px / `letter-spacing:.14em` / 500 —— 丝印感，全部用在 `.sec-title`、`.scope-live-k`、`.kv-k` 这类"名字"上
- 读数层：`ui-monospace` + `tabular-nums` / 17–21px / 700 —— 数字永远等宽对齐，像表盘读数（`.scope-live-v`、`.hm-val`、`.kv-v`、`.tire-v`、`.ac-temp-val`）
- 正文：系统 sans / 15px，不加花哨字重
- 不引入第三方字体文件（APK 体积 + 授权），靠字距与等宽做出仪表差异

**签名元素（Signature）**：**刻度脊（tick rail）**
每张卡片左缘一条 3px 铝脊，脊上每 7px 一枚 1px 短刻度，顶端一小段琥珀"通电"指示。
它编码真实信息：琥珀段存在 = 这张卡当前是"活的"（有数据/已启用），灰脊 = 静态配置卡。
这个元素只可能属于仪表世界——换到落地页或后台表格上就毫无意义，所以它是选择而不是默认值。

## 刻意避开的三条默认长相

- 不用暖奶油底 + 衬线大标题 + 陶土色
- 不用"近黑 + 单一酸性亮色 + 大圆角发光"那套（原 3.x 蓝色渐变就偏这个方向，本次主动收掉）
- 不用报纸式发丝分栏

改动只走 CSS：`assets/v4.css` 在 `styles.css` 之后加载，**不动任何 DOM id、类名与 JS 逻辑**，回到旧皮只需删掉一行 `<link>`。
