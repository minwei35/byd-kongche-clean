# 安全精简试用版实施计划

目标：保留扫码授权和本地 BLE 控车，移除巴法云及同步、明文导出和不可信更新，日志仅上传至独立证书固定 TLS 服务。

1. 在新 build_secure.py 从干净原 APK 解码树构建，复用试用签名并提高 versionCode，保留所有钥匙 prefs；原包不覆盖。
2. 巴法云相关联网/启动/同步/恢复入口改为无副作用，UI功能正文撤下；保留必需兼容节点避免 JS 初始化失败。
3. 更新源为空、下载入口关闭、更新说明使用textContent；页面CSP、WebView禁止任意file访问；原生桥不返回账号秘密。
4. 在AppLog.add入口做结构化诊断过滤：包含凭据或原始云响应的记录只保留事件标签；任何20字节认证载荷不记录；关闭原RAW_DUMP。历史原日志文件清空，只在日志子目录处理。
5. 独立TLS收集服务8788，仅health和POST applog；独立日志token、限流/限长/恒定时间校验，绝无车控路由。
6. 新APK不包含token。TLS证书公钥/证书固定；用ADB intent一次性配置独立日志token到已有加密CredentialManager（手机不在时由用户稍后连接配置）。旧共用车控token轮换，原Clean本机token文件同步更新，其他设备需重新配置。
7. 测试端点分权、TLS固定、过滤、更新撤下、巴法云调用无副作用；签名、对齐、BLE源码一致性；设备连接则覆盖安装、确认扫码凭据仍配置、实际日志入库。

边界：不改BLE协议和JNI；不宣称native/云后端全部无漏洞；不发送任何实车控制命令。移除巴法云后小爱/云同步/自定义巴法云卡失效是预期精简。
